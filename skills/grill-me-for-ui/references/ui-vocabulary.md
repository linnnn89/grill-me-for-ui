# UI Vocabulary Map

本文件帮助 Agent 把用户描述的可观察效果映射为准确的前端 UI 术语。先确认行为，再使用术语；不要要求用户先懂术语。

## 页面结构与布局

| 用户可能会说 | 术语 | 适合情况 | 需要避免的误用 |
|---|---|---|---|
| 顶部一条放 logo、栏目和登录 | Header / Navbar | 官网、顶级栏目较少 | 功能很多时硬塞进顶部 |
| 左边一列功能，右边是工作区 | Sidebar Layout | 后台、Dashboard、高频模块切换 | 简单落地页或移动端常驻宽侧栏 |
| 所有内容往下滚完 | Single Page | 线性叙事、简单官网 | 复杂工具强行塞成一页 |
| 左目录、中正文、右侧本页目录 | Doc Layout | 文档、知识库、长内容 | 短内容增加无效导航 |
| 内容做成自动换列的卡片 | Card Grid | 同类对象浏览 | 多字段精确比较 |
| 中间窄栏、两边留白 | Centered Column | 阅读、写作、简单表单 | 数据密集工作台 |
| 元素一行排列并对齐 | Flex | 一维排列 | 复杂二维网格硬用 Flex |
| 卡片整齐排成多行多列 | Grid | 二维布局、响应式卡片 | 简单一行布局过度复杂化 |
| 滚动时还固定在顶部 | Sticky | 工具栏、目录、关键操作 | 占据过多移动端空间 |

## 内容与数据展示

| 用户可能会说 | 术语 | 适合情况 | 需要避免的误用 |
|---|---|---|---|
| 每条数据一行，按列比较 | Table | 多字段、排序、筛选、比较 | 手机端直接压缩所有列 |
| 内容一条条排下来 | List | 线性浏览、结构较简单 | 需要跨列比较的数据 |
| 每个项目一张小块 | Card | 对象摘要、可点击入口 | 用卡片包住页面上的每一项 |
| 首页几个特别大的数字 | Statistic / KPI Card | 核心指标概览 | 用指标卡代替分析和上下文 |
| 分几个页签切换内容 | Tabs | 同层级相关内容 | 把关键顺序流程藏进 Tabs |
| 两三个选项并排切换 | Segmented Control | 少量互斥视图或模式 | 大量或长文本选项 |
| 点击标题展开答案 | Collapse / Accordion | FAQ、次级信息 | 隐藏用户完成任务必需的信息 |
| 按时间展示进展 | Timeline | 历史、物流、事件过程 | 非时间序列内容 |
| 没数据时给下一步 | Empty State | 首次使用、无搜索结果 | 只放插画，不给行动建议 |
| 标题太长显示省略号 | Text Truncate | 空间固定的列表和卡片 | 隐藏关键信息且无查看方式 |

## 表单与选择

| 用户可能会说 | 术语 | 适合情况 | 需要避免的误用 |
|---|---|---|---|
| 填一行文字 | Input | 短文本 | 长描述或多段内容 |
| 写一大段话 | Textarea | 长文本 | 单值短输入 |
| 几个选项只能选一个 | Radio | 少量互斥选项 | 大量选项 |
| 可以同时选多个 | Checkbox | 独立多选 | 单一开关 |
| 拨一下立即开关 | Switch | 二元且立即生效 | 需要提交确认的高风险操作 |
| 选项收起来再选 | Select | 中等数量候选 | 高频少量选项增加点击成本 |
| 输入几个字自动搜索候选 | AutoComplete / Combobox | 大量候选、可搜索 | 候选很少 |
| 选日期或时间 | DatePicker / TimePicker | 结构化日期时间 | 需要输入模糊自然语言日期 |
| 上传图片或文件 | Upload | 文件输入 | 无进度、大小和失败反馈 |
| 多个字段统一验证提交 | Form | 注册、编辑、查询条件 | 每个设置本应立即生效却强制总保存 |
| 每栏写清楚填什么 | Label | 所有需要识别的表单控件 | 只依赖 placeholder 充当标签 |

## 弹窗、详情与反馈

| 用户可能会说 | 术语 | 适合情况 | 需要避免的误用 |
|---|---|---|---|
| 屏幕中间弹框，背景变暗 | Modal | 短而聚焦、需要阻塞背景的任务 | 长表单、复杂详情、频繁操作 |
| 从右边滑出详情，列表还在 | Drawer | 保留上下文的详情或编辑 | 移动端层级过深仍无限套 Drawer |
| 删除按钮旁边问确定吗 | Popconfirm | 邻近、简单、低复杂度确认 | 需要解释后果的高风险操作 |
| 点头像旁边浮出小卡片 | Popover | 轻量补充内容和操作 | 重要内容只在悬浮层里 |
| 鼠标放上去解释图标 | Tooltip | 简短辅助说明 | 移动端唯一的信息来源 |
| 保存后角落提示一下 | Toast | 非阻塞、短暂结果反馈 | 需要用户持续处理的重要错误 |
| 页面上一直挂着重要提示 | Alert | 持续、需要关注的信息 | 每个普通反馈都用 Alert |
| 右上角铃铛消息列表 | Notification | 异步系统消息 | 当前操作的即时结果 |
| 上传到多少了 | Progress | 可量化进度 | 无法估算进度却给虚假百分比 |
| 加载时先放灰色框 | Skeleton | 结构可预测的内容加载 | 不确定结构或极短加载 |
| 加载时转圈 | Spinner | 短时、局部等待 | 长时间全屏阻塞且无说明 |
| 完成后显示搞定页面 | Result / Success State | 明确流程终点 | 简单保存后强制跳离上下文 |

## 导航与流程

| 用户可能会说 | 术语 | 适合情况 | 需要避免的误用 |
|---|---|---|---|
| 功能越来越多，需要入口列表 | Menu | 导航或操作集合 | 把主要动作藏进更多菜单 |
| 顶部显示当前在哪一层 | Breadcrumb | 深层层级导航 | 只有一两层仍增加噪音 |
| 数据太多需要翻页 | Pagination | 离散页、可定位结果 | 连续浏览或实时流 |
| 顶部显示现在第几步 | Steps / Stepper | 明确顺序的多步任务 | 可自由切换的平级内容 |
| 点用户名展开设置退出 | Dropdown | 紧凑操作菜单 | 重要主操作过度隐藏 |
| 页面右侧目录点了跳段落 | Anchor / TOC | 长页面、文档 | 短页面 |
| 键盘一步跳到正文 | Skip Link | 有重复导航的可访问页面 | 不应以视觉噪音方式常驻 |

## 官网与转化区块

| 用户可能会说 | 术语 | 适合情况 | 需要避免的误用 |
|---|---|---|---|
| 首屏大标题说明我们做什么 | Hero | 落地页首要承诺 | 大图占满却说不清价值 |
| 显眼按钮让人免费试用 | CTA | 核心转化动作 | 同屏多个同强度主 CTA |
| 放客户 logo 和使用数据 | Social Proof | 建立可信度 | 虚构数字或无来源背书 |
| 用户评价 | Testimonial / User Voice | 降低决策疑虑 | 过长、无具体结果的空泛赞美 |
| 三档套餐并排 | Pricing | 可比较的定价方案 | 复杂定价强行三卡片 |
| 常见问题一问一答 | FAQ | 处理重复疑虑 | 用 FAQ 弥补主内容说不清 |
| 页面底部链接和版权 | Footer | 补充导航和法务信息 | 堆满与任务无关链接 |

## 视觉与层级

| 用户可能会说 | 术语 | 需要确认的实际规则 |
|---|---|---|
| 重点不清楚 | Visual Hierarchy / Typography | 标题、正文、次要信息的字号、字重、颜色和间距 |
| 元素挤在一起 | Spacing | 相关靠近、不同组拉开；使用一致间距尺度 |
| 字贴着盒子边缘 | Padding | 内容与容器边界的内部留白 |
| 两块之间太贴 | Margin / Gap | 组件或分组之间的外部距离 |
| 卡片柔和一点 | Border Radius | 圆角尺度与全站一致性 |
| 卡片像浮起来 | Shadow / Elevation | 阴影是否表达层级而非纯装饰 |
| 背景蓝到紫 | Gradient | 渐变是否服务品牌或层级，文字对比是否足够 |
| 半透明模糊导航 | Backdrop Blur / Glass | 可读性、性能和降级方案 |
| 图片别太抢 | Opacity / Overlay | 对比度和内容可读性 |

## 交互与动效

| 用户可能会说 | 术语 | 需要确认的实际规则 |
|---|---|---|
| 鼠标放上去变色 | Hover | 仅桌面指针设备，不替代 Focus |
| 按下去有反馈 | Active / Pressed | 短暂按压或状态锁定 |
| Tab 时看得出在哪 | Focus | 清晰可见、顺序合理、不被裁切 |
| 没填完按钮灰掉 | Disabled | 同时解释为什么不可用，必要时允许点击后提示 |
| 切换别太突兀 | Transition | 属性、时长、缓动和 reduced motion |
| 弹窗轻微回弹 | Spring | 低频、短时，不影响操作 |
| 旧内容淡出新内容淡入 | Fade | 避免造成等待或丢失空间关系 |
| 拖动卡片换顺序 | Drag and Drop | 键盘替代、落点、撤销和移动端手势 |

## 使用方式

1. 从用户描述提炼行为、位置、持续时间和后果。
2. 在候选术语中比较适用边界，不默认第一个词正确。
3. 用一句自然语言确认：“你描述的更接近 Drawer：从侧边打开详情，同时保留列表上下文。”
4. 只有这个术语会改变设计时，才把它变成访谈问题。
5. 用户不需要记住术语；最终 UI brief 中使用准确术语以方便实现。
