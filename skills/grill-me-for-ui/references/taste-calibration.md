# Taste Calibration for UI Interviews

本文件用于把“高级、现代、有设计感、不要 AI 味”转化为明确的艺术指导、视觉系统和可验收的设计判断。

它不是一份流行风格清单，也不靠禁止若干字体、渐变或布局来制造品味。真正成熟的审美来自：读懂情境、选择清晰立场、建立视觉张力、控制节奏，并让每个细节服从同一套概念。

## 一、设计立场

高级感通常不是“更多”，而是以下能力的组合：

- **判断准确**：知道这个产品此刻应该像什么，也知道不应该像什么；
- **立场清晰**：不把多个安全方案平均成没有性格的中间值；
- **概念统一**：构图、排版、色彩、图像、材质和动效来自同一个核心概念；
- **张弛有度**：建立主次、密疏、轻重、静动之间的对比；
- **细节克制**：减少没有功能或叙事价值的装饰；
- **内容真实**：真实内容决定布局，不用假数据和空洞文案填满设计；
- **落地可靠**：美感不能以可读性、响应式、性能和可访问性为代价。

不要把“安全、规范、无错误”误认为高级审美。没有明显错误但没有视觉立场的页面，仍然可能平庸。

## 二、先判断设计自由度

### 1. 界面类型

| 类型 | 首要价值 | 可用的审美自由度 | 常见风险 |
|---|---|---|---|
| 产品 / 工作流 UI | 效率、反馈、连续操作 | 中低 | 为了独特而干扰操作 |
| Dashboard / 数据工具 | 扫读、比较、密度、可信 | 中低 | Card 堆砌、层级平均化 |
| 营销页 / 官网 | 品牌记忆、叙事、转化 | 中高 | 通用 SaaS Hero 模板 |
| Portfolio / 创意展示 | 个性、节奏、作品呈现 | 高 | 动效和自我表达压过作品 |
| Editorial / 内容产品 | 阅读、排版、内容气质 | 中高 | 用大衬线和米色冒充编辑感 |
| 消费型移动端 | 触感、情绪、高频任务 | 中 | 把概念稿效果带入长期使用 |
| 社区 / 娱乐产品 | 归属感、活力、参与 | 中高 | 视觉噪声、元素失控 |
| 奢侈 / 时尚 / 文化品牌 | 欲望、态度、稀缺感 | 高 | 套用黑白大图而缺少真正观点 |
| 设计系统 | 一致性、组合和扩展 | 中 | 规则过多、例外无治理 |
| 信任优先场景 | 清楚、可追溯、无障碍 | 中低 | 将克制误解为无辨识度模板 |

### 2. 五个约束信号

在讨论视觉前，读取：

- **任务频率**：每天重复操作，还是低频浏览；
- **错误代价**：误点、误读或误判会造成什么后果；
- **信任要求**：用户是否需要理解来源、状态和限制；
- **品牌表达需求**：是否必须快速留下记忆；
- **内容资产质量**：是否拥有足够好的文案、图片、插画、数据或作品。

高频、高风险和高信任要求会降低实验自由度；低频、品牌主导和高质量内容资产允许更强表达。但“克制”不等于没有性格，“大胆”也不等于堆叠效果。

## 三、形成 Art Direction Card

在进入具体布局和组件前，先形成一张简短的艺术指导卡。

```text
界面类型：
受众与任务：
视觉气质：三个具体形容词 + 一个明确反形容词
主导概念：一句话视觉命题
主要张力：例如“精密 × 亲和”“秩序 × 活力”
表达媒介：构图 / 排版 / 图像 / 色彩 / 材质 / 动效中的主导项
设计风险：最容易滑向的模板化或过度设计方向
```

### 好的气质描述

使用能够改变设计的词：

- 冷静、精密、克制，但不冰冷；
- 明亮、乐观、触感明确，但不幼稚；
- 编辑化、文化感、节奏鲜明，但不复古做作；
- 技术性、密集、快速扫读，但不赛博霓虹；
- 奢华、留白、具有距离感，但不空洞。

避免只写：现代、高级、简洁、科技感、Apple 风、Awwwards 风。

### 视觉命题

视觉命题应说明如何产生目标感受：

```text
以[主导构图 / 排版 / 图像 / 材质]建立[目标感受]，
通过[主要对比或节奏]强化[核心内容]，
其余元素保持[克制原则]，避免[最可能的风格漂移]。
```

示例：

> 以宽窄交替的编辑网格和强烈标题比例建立文化品牌的自信感，通过高质量人物摄影与大面积空白形成张力；控件和装饰保持安静，避免滑向通用奢侈品黑金模板。

## 四、三项审美旋钮

数字用于校准，不是质量评分，也不是必须展示给用户的设置面板。

### `EXPRESSION`：视觉表达度

- 1–3：高度克制、熟悉、信任优先；
- 4–6：有明确性格，仍以任务或内容为中心；
- 7–8：品牌和视觉叙事显著；
- 9–10：艺术表达主导，仅适合少数低风险场景。

### `MOTION`：动效强度

- 1–2：仅状态反馈；
- 3–5：展开、切换和空间关系动画；
- 6–8：有编排的进入、滚动或叙事动效；
- 9–10：时间体验本身成为作品，需要强性能与降级方案。

### `DENSITY`：信息密度

- 1–3：画廊、品牌展示、沉浸阅读；
- 4–6：普通产品和消费应用；
- 7–8：专业工具、Dashboard、表格；
- 9–10：高熟练度驾驶舱，需要强层级、快捷操作和定制能力。

### 情境起点

| 场景 | EXPRESSION | MOTION | DENSITY |
|---|---:|---:|---:|
| 专业工作流 | 2–5 | 1–4 | 6–9 |
| B2B SaaS 产品界面 | 3–6 | 2–5 | 5–8 |
| 数据分析 Dashboard | 3–5 | 1–4 | 7–9 |
| 主流 SaaS Landing | 5–8 | 3–7 | 3–5 |
| 创意机构 / Portfolio | 7–9 | 5–8 | 2–5 |
| Editorial / 内容品牌 | 5–8 | 2–6 | 2–5 |
| 消费型移动端 | 4–7 | 3–6 | 4–7 |
| 时尚 / 文化品牌 | 7–9 | 3–7 | 1–4 |
| 社区 / 娱乐产品 | 5–8 | 4–7 | 4–7 |

## 五、一个主导概念，最多两个支持母题

“一个页面只能有一个亮点”过于机械。更准确的规则是：

- **一个主导概念**决定页面的整体识别；
- **最多两个支持母题**重复出现，用来强化主导概念；
- 其他细节保持从属，不各自争夺注意力。

### 主导概念示例

- 编辑化的非对称网格；
- 极强的数字与数据排版秩序；
- 电影式全幅影像叙事；
- 模块化工业结构；
- 轻盈、透明、漂浮的空间感；
- 纸张、印刷和批注式阅读体验；
- 连续画布式工具工作流。

### 支持母题示例

- 固定的裁切比例；
- 重复的竖线或编号系统；
- 一致的超大数字；
- 特定形状语言；
- 单一材质逻辑；
- 一种短促而有因果关系的动效；
- 一套稳定的留白节奏。

检查：

1. 主导概念是否服务内容、产品和受众；
2. 用户是否能在五秒内感知它；
3. 去掉它后页面是否迅速变成通用模板；
4. 支持母题是否强化而非竞争；
5. 它是否会损害任务、性能或可访问性。

## 六、构图语法：高级感首先来自宏观秩序

在选择 Card、Button 或字体前，先确定页面的构图语法。

### 1. Anchor：视觉锚点

页面必须有一个首先被看到的视觉锚点。它可以是标题、产品画面、人物摄影、关键数据或主要操作，而不是自动等于 Hero H1。

### 2. Flow：视线流动

设计视线从哪里进入，经过什么，再到哪里结束。避免所有模块视觉权重相等，也避免用户必须靠滚动猜测结构。

### 3. Rhythm：节奏

通过密疏、大小、长短、规则与破格形成节奏。连续使用相同三列卡片、相同上下间距和相同标题结构，会让页面像模板。

### 4. Contrast：对比

每个页面至少需要一种明确对比：

- 大与小；
- 密与疏；
- 静与动；
- 图像与文字；
- 明与暗；
- 精密与柔和；
- 规则与一次有意破格。

对比不是随机差异，而是用来强化层级和概念。

### 5. Breathing：呼吸

留白必须有角色：聚焦、分组、停顿或营造张力。平均分配的空白不是节奏，只是间距。

### 6. Edge：边缘意识

检查页面四周、容器边界、裁切和对齐关系。成熟设计往往在边缘处理上更坚定：要么严格对齐，要么明确出血，不要半截犹豫。

## 七、视觉系统六层

### 1. Typography：排版声音

先确定排版角色，再选字体：

- 标题是权威、理性、友好、戏剧化还是编辑化；
- 标题与正文的比例靠字号、字重、字宽、行距还是颜色建立；
- 行长和断行是否形成设计，而不是由浏览器偶然决定；
- 数字、标签、元数据和正文是否需要不同节奏；
- CJK 与拉丁混排、长标题和本地化如何保持层级；
- 是否需要一套字体完成，还是有明确理由使用两套字体。

不要把“找到一个冷门字体”误认为排版设计。

### 2. Color：色彩架构

区分三类颜色：

- **Atmosphere**：决定整体温度和情绪的背景与中性色；
- **Action**：突出品牌、重点和主要交互；
- **Semantic**：成功、警告、错误、信息和数据类别。

一个强调色只是常见方案，不是铁律。需要多个颜色时，必须有角色和层级，不能每个区块重新配色。

### 3. Shape：形状语言

明确：

- 圆角、直角、切角、圆形或不规则形状分别承担什么角色；
- 按钮、输入、Card、Tag 和图片是否属于同一形状家族；
- 是否存在一个可复用的品牌轮廓；
- 图标的线宽、端点、填充和视觉重量是否统一。

### 4. Material & Depth：材质和深度

选择一种主要材质逻辑：

- 平面 / 编辑式；
- 边框 / 结构式；
- 色块 / 层叠式；
- 阴影 / 空间式；
- 透明 / 大气式；
- 纸张 / 纹理式。

允许混合，但必须按层级分工。玻璃、阴影、噪点和渐变不应同时成为主角。

### 5. Imagery & Illustration：图像策略

营销、品牌、Editorial 和 Portfolio 页面若依赖图像表达，必须确认素材策略：

- 摄影主题、镜头距离、光线、色调和裁切；
- 人物是否看向镜头、产品还是动作方向；
- 图片是证据、情绪、叙事还是装饰；
- 插画的几何、笔触、透视和色彩规则；
- 图标与插画是否混用；
- 素材质量不足时，是否应降低图像在概念中的权重。

不要用低质量随机图库图支撑一个声称“高级”的视觉概念。

### 6. Motion：时间设计

动效应具有时间层级：

- **即时反馈**：Hover、Press、Focus、Validation；
- **空间解释**：展开、切换、列表到详情；
- **叙事编排**：页面进入、滚动、章节过渡；
- **环境运动**：持续背景或氛围，仅在确有价值时使用。

高频产品操作优先快速稳定；低频展示体验可以更有编排。任何强动效都需要 reduced motion、低性能设备和中断策略。

## 八、参考设计采用三角拆解

不要只模仿一个网站。理想情况下从 2–3 个参考中分别提取：

1. **构图参考**：页面秩序与视线；
2. **排版或色彩参考**：视觉声音；
3. **图像、材质或动效参考**：品牌触感。

每个参考只借一到两个维度，并明确：

| 参考 | 借鉴维度 | 不借鉴什么 | 转化为当前项目的规则 |
|---|---|---|---|
|  |  |  |  |

这样可以降低复制感，也能让设计方向更适合当前内容。

## 九、情境化 Anti-Slop Gate

### 1. 产品特异性

- 隐去 Logo 后，是否仍能看出它服务什么产品和用户；
- 内容、数据和操作是否真实驱动布局；
- 是否存在替换文案后仍完全成立的模板区块。

### 2. 视觉立场

- Art Direction Card 是否清晰；
- 第一眼是否能感到主导概念；
- 是否因为害怕犯错而退回无个性的安全模板。

### 3. 视觉主导

- 主导概念是否唯一；
- 支持母题是否不超过两个并保持从属；
- 是否同时堆叠渐变、玻璃、噪点、Bento、大标题和复杂动画。

### 4. 构图与节奏

- 页面是否存在视觉锚点和视线流；
- 是否连续重复相同区块结构；
- 密疏、大小和停顿是否有意安排；
- 边缘、裁切和对齐是否坚定。

### 5. 系统一致性

- 排版、色彩、形状和材质是否来自同一概念；
- 强调色、语义色和状态色是否角色清晰；
- 每个区域是否像由不同模板拼接而成。

### 6. 组件必要性

- Card、Badge、Chip、Eyebrow、Tooltip 是否承担真实信息功能；
- 相同意图是否使用一致 CTA；
- 是否为了填满页面创造假指标、客户 Logo、功能项或社会证明。

### 7. 动效因果

- 动画是否解释状态、空间或叙事；
- 是否有持续循环动画无理由争夺注意力；
- 高频操作是否足够快；
- 是否有可用降级方案。

### 8. 内容与可信度

- 不生成未提供的指标、评价、客户、奖项和统计；
- Placeholder 明确标注；
- AI 生成内容、数据时间和不确定性透明。

### 9. 响应式与可访问性

- 移动端是否重新编排核心任务，而不是机械单列；
- 表格、图表、全幅图像和复杂构图是否有小屏策略；
- 对比度、Focus、键盘、点击目标和内容增长满足边界。

## 十、不要使用绝对审美禁令

以下只能作为偏差提醒：

- 禁止 Inter、衬线、纯黑；
- 禁止居中 Hero、三列卡片或 Card；
- 必须只有一个强调色；
- 必须非对称；
- 所有页面都要强动效；
- 所有移动端都必须单列；
- 大圆角、Bento 或毛玻璃才高级。

正确判断是：这个选择是否强化当前 Art Direction Card、内容层级和用户任务。

## 十一、适合访谈的审美问题

一次只问一个，并给出明确推荐：

- 用户五秒后最应该记住的是内容、品牌态度、产品能力还是某个操作结果？
- 这页的主要张力更适合来自“秩序 × 破格”“精密 × 亲和”，还是“克制 × 戏剧性”？
- 视觉识别应主要来自构图、排版、图像、色彩、材质还是动效？
- 页面更需要稳定重复的系统感，还是有意安排的一次破格？
- 参考中真正想借的是构图、排版、色彩、图像、材质还是时间节奏？
- 当前页面最缺的是视觉锚点、层级对比、节奏、内容质量还是品牌母题？
- 哪个元素应该最有声音，哪些元素必须退后？
- 如果只能保留一个主导概念，应该是什么？

## 十二、实施后的视觉复核

完成线框图、视觉稿或前端实现后，只使用 `visual-critique.md` 的有界协议：Pass 1 批量发现、一个 Fix batch、Pass 2 确认后停止。需求完整并不代表设计已经好看；最终质量必须通过真实截图、真实内容和目标视口验证。
