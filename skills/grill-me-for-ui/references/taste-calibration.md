# Taste Calibration

仅在任务需要完整 Art Direction、构图系统或明确审美验收时读取。日常 Extension 与常规 Refinement 使用 `core-cheatsheet.md`；复杂品牌世界或需要解释判断依据时再读取 `taste-deep.md`。

## 1. 先定自由度

视觉表达不能脱离以下信号：

- 任务频率与熟练度；
- 错误代价与信任要求；
- 品牌记忆的重要性；
- 内容和视觉资产质量；
- 平台、性能与无障碍边界。

高频、高风险、高信任通常降低实验自由度；低频、品牌主导和高质量资产允许更强表达。克制不等于无性格，大胆不等于堆效果。

## 2. Art Direction Card

```text
界面类型：
受众与任务：
视觉气质：三个具体形容词 + 一个反形容词
主导概念：一句话视觉命题
主要张力：
第一视觉锚点：
主导表达媒介：构图 / 排版 / 图像 / 色彩 / 材质 / 动效
必须复用与允许偏离：
最大设计风险：
```

视觉命题说明如何产生目标感受：

```text
以[主导媒介]建立[目标感受]，
通过[主要对比或节奏]强化[核心内容]，
其余元素保持[克制原则]，避免[风格漂移]。
```

避免“现代、高级、简洁、科技感”这类不改变设计的词。

## 3. 三个校准旋钮

数字是边界，不是质量分：

| 旋钮 | 低 | 中 | 高 |
|---|---|---|---|
| Expression | 1–3 克制、熟悉、信任优先 | 4–6 有性格但任务优先 | 7–10 品牌或艺术表达主导 |
| Motion | 1–2 状态反馈 | 3–5 空间关系 | 6–10 编排、叙事或时间体验 |
| Density | 1–3 展示、沉浸阅读 | 4–6 常规产品 | 7–10 专业工具与驾驶舱 |

高表达或强动效必须同时说明性能、打断和降级；高密度必须同时说明层级、扫描和快捷操作。

## 4. 主导概念与构图

- 一个主导概念决定整体识别；
- 最多两个支持母题重复强化；
- 其他细节保持从属；
- 去掉主导概念后若页面立刻变成通用模板，说明它具有识别价值；
- 若概念损害任务、内容、性能或可访问性，降低表达而不是为效果辩护。

先检查宏观构图，再讨论组件细节：

| 语法 | 必须回答 |
|---|---|
| Anchor | 第一眼应该看到什么 |
| Flow | 视线如何进入、经过并结束 |
| Rhythm | 密疏、大小、长短如何形成节奏 |
| Contrast | 哪一种对比强化层级 |
| Breathing | 留白承担聚焦、分组还是停顿 |
| Edge | 对齐、裁切和出血是否坚定 |

## 5. Anti-Slop Gate

交付前检查：

- 隐去 Logo 后，仍能看出服务的产品、内容和用户；
- 第一眼与 Art Direction Card 一致；
- 识别点不只来自颜色、渐变或圆角；
- 真实内容驱动布局，没有假指标、客户或评价；
- Placeholder 明确标注；AI 生成内容、数据时间和不确定性保持透明；
- 构图有锚点、视线流和密疏节奏，不是均匀 Card 堆叠；
- Type、Color、Form、Space、Material、Motion 来自同一方向；
- 动效解释反馈、空间或叙事，不无理由争夺注意力；
- 小屏、状态、内容增长和无障碍仍保留主导概念。

不要使用“禁止 Inter / 居中 Hero / 三列 Card / 渐变 / Bento”等绝对审美禁令。判断标准只有：是否服务当前任务、内容和 Art Direction。

## 6. 停止

Art Direction Card、主导概念、构图语法、旋钮边界和最大风险都足以排除主要替代方向时停止。不要为了补全所有视觉维度继续提问。

只有需要完整视觉系统、参考转译、图像与材质策略或复杂审美论证时，才读取 `taste-deep.md`。
