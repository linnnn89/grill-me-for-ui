## 1. 情境化设计自由度

| 表面 | 首要价值 | 常见风险 |
|---|---|---|
| 产品 / 工作流 | 效率、反馈、连续操作 | 为独特而干扰任务 |
| Dashboard / 数据工具 | 扫读、比较、密度、可信 | Card 堆砌、层级平均 |
| 营销页 / 官网 | 记忆、叙事、转化 | 通用 SaaS Hero |
| Portfolio / 创意展示 | 个性、节奏、作品 | 界面压过作品 |
| Editorial / 内容 | 阅读、排版、内容气质 | 用衬线和米色冒充编辑感 |
| 消费移动端 | 触感、情绪、高频任务 | 概念稿效果妨碍长期使用 |
| 社区 / 娱乐 | 归属、活力、参与 | 视觉噪声失控 |
| 时尚 / 文化品牌 | 欲望、态度、稀缺 | 黑白大图但没有观点 |
| 信任优先场景 | 清楚、可追溯、无障碍 | 把克制做成无辨识度模板 |

## 2. 七维视觉系统

### Form

- 控件、容器、图片和图标是否属于同一形状家族；
- 圆角、直角、切角和不规则形状各承担什么角色；
- 品牌轮廓能否稳定重复，而不是每区块重新发明。

### Color

分开三个角色：

- **Atmosphere**：背景、中性色与整体温度；
- **Action**：品牌重点与主要交互；
- **Semantic**：成功、警告、错误、信息和数据类别。

强调色可以不止一个，但必须有角色和层级。

### Type

- 标题是权威、理性、友好、戏剧还是编辑化；
- 标题、正文、数据、标签和元信息各有稳定角色；
- 行长、断行、字重和行距有意设计；
- CJK、拉丁、数字和本地化不会破坏层级。

冷门字体不是排版策略。

### Space

- 网格是否支持任务与内容；
- 密疏、停顿、规则与一次破格形成节奏；
- 留白用于聚焦、分组或张力，而不是平均撒开；
- 页面边缘、裁切、对齐与出血明确。

### Material

选择一种主要逻辑：平面、边框、色块、阴影、透明、纸张或纹理。允许混合，但必须按层级分工；玻璃、阴影、噪点和渐变不应同时成为主角。

### Motion

- 即时反馈：Hover、Press、Focus、Validation；
- 空间解释：展开、切换、列表到详情；
- 叙事编排：进入、滚动、章节过渡；
- 环境运动：仅在持续氛围确有价值时使用。

强动效必须定义退出、打断、reduced motion 和低性能回退。

### Cultural markers

- 哪些信号是方向不可缺少的；
- 它们来自什么文化或媒介语境；
- 是否可能被误解、过时或形成行业刻板映射；
- 去掉表面符号后，信息结构和内容选择是否仍支持该方向。

## 3. 图像、插画与数据表达

确认素材的主题、镜头距离、光线、色调、裁切和用途。图片必须是证据、情绪、叙事或内容，而不是随机填充。

插画要统一几何、笔触、透视和色彩规则；图标选择一个主家族。数据图形根据比较、趋势、分布或关系选择，不用假数据支撑视觉完成度。

素材质量不足时，降低它在主导概念中的权重。

## 4. Reference Triangle

不要完整模仿一个网站。从 2–3 个参考分别提取：

1. 构图与视线；
2. 排版或色彩声音；
3. 图像、材质或时间触感。

## 5. 深度判断问题

一次只问一个：

- 五秒后最应记住内容、品牌态度、产品能力还是操作结果？
- 张力应来自秩序 × 破格、精密 × 亲和，还是克制 × 戏剧？
- 识别主要来自构图、排版、图像、色彩、材质还是动效？
- 哪个元素应该最有声音，哪些必须退后？
- 哪项参考特征适合借用，哪项会损害当前产品？
- 如果只能保留一个主导概念，它是什么？

## 6. 深度停止条件

只有当复杂方向已被转化为可实现的构图、视觉系统、资产要求、技术代价与风险时停止。若深度分析没有改变 Art Direction Card 或验收边界，沿用已加载的轻量结论，不重新读取文件或继续扩展。
