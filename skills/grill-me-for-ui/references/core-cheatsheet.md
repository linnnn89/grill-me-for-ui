# Core Design Cheatsheet

用于已有基线上的 T1/T2 Extension 和方向正确的常规 Refinement。它不是缩小版全流程：若分类、视觉身份或产品方向仍不确定，返回主 Router 选择其他 Playbook。

## 快速判断

| 维度 | 选择依据 |
|---|---|
| Persuade | 主要成功是理解价值并行动 |
| Operate | 主要成功是高效、安全完成任务 |
| Read | 主要成功是理解、定位并保留信息 |
| Experience | 内容或作品本身成为体验 |

| 路径 | 最小动作 |
|---|---|
| Extension T1 | 回放相关契约；问新页面任务、入口、锚点和新增能力 |
| Extension T2 | 回放相邻 Section；问顺序、层级、复用和节奏 |
| Refinement | 确认视觉身份正确；声明核心失败、重写深度和一个动作 |
| T3 / 已定位微调 | 退出本 Playbook，直接实施并定向 Review |

Extension 默认只问 1–3 个当前表面问题，不重新研究全站。Refinement 若发现视觉身份错误，停止并请求 World Replacement 授权。

Refinement 深度：Light 只调层级、排版与细节；Medium 可重组布局和组件层级；Full structural 可重建结构与实现，但三者都必须保留现有视觉身份。

高风险 Operate 还要锁定角色权限、失败与恢复；若这些会改变产品范围，停止轻量路径，下一阶段再进入 `interview-map.md`。

## 动作速选

| 症状 | 主动作 |
|---|---|
| 方向或需求仍模糊 | shape |
| 不知道为什么不对 | critique |
| 整体完成度不足 | polish |
| 安全、平均、无观点 | bolder |
| 元素争抢注意力 | quieter |
| 内容或容器堆叠 | distill |
| 字级、行长、断行失控 | typeset |
| 锚点、层级、节奏错误 | layout |
| 色彩角色混乱 | colorize |
| 时间反馈或空间关系不足 | animate |
| 状态、极值、无障碍不足 | harden |
| 平台或设备不成立 | adapt |

一次只选一个主动作，最多一个支持动作。

## Mini Art Direction Card

```text
三个具体气质词 + 一个反形容词：
主导概念：
主要张力：
第一视觉锚点：
主导表达媒介：
必须复用：
允许偏离：
最大设计风险：
```

用三个旋钮校准边界，不把它们当评分：

- **Expression**：1–3 克制与信任；4–6 有性格但任务优先；7–10 品牌或艺术表达主导。
- **Motion**：1–2 状态反馈；3–5 空间解释；6–10 编排或时间体验。
- **Density**：1–3 展示与沉浸；4–6 常规产品；7–10 专业工具与驾驶舱。

## 七维最小检查

- **Form**：形状家族和控件关系；
- **Color**：Atmosphere / Action / Semantic 分工；
- **Type**：标题、正文、数据和 CJK 层级；
- **Space**：网格、密疏、停顿和边缘；
- **Material**：一种主材质逻辑；
- **Motion**：反馈、空间或叙事的因果；
- **Cultural markers**：必要信号、误读与刻板风险。

只展开会改变本轮方案的维度。

## 停止

满足以下条件即交付局部决定或修改边界：

- 当前任务、范围、保留项和非目标明确；
- Art Direction 继续成立；
- 主动作及预期效果明确；
- 剩余问题可在实现或一次定向 Review 中解决。

不要生成完整方向研究、全站 Brief 或 DESIGN.md，除非任务另有独立触发条件。
