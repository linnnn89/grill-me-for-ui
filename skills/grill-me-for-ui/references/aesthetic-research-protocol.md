# Aesthetic Research Protocol

本文件用于在用户表达“像某种风格”“更有品味”“不要通用 SaaS 感”时，进行有边界的审美研究。目标不是枚举风格名，而是把文化语言、参考图和视觉直觉转化为当前产品可实现的 Art Direction。

## 一、何时使用

使用本协议：

- 风格词存在多种解释；
- 用户引用品牌、艺术流派、年代、电影或文化场景；
- 项目需要明显品牌身份；
- 方向胶囊需要外部参考支撑；
- 现有设计看似完整但缺乏文化和视觉特异性。

不要使用：

- 需求已经被成熟设计系统约束；
- 只是 T3 微调；
- 用户只要求修复功能、对比度或响应式错误；
- 大量研究不会改变最终方向。

## 二、先消歧，再应用

### 1. 提取用户真正描述的信号

区分：

- **明确审美名**：Brutalism、Dark Academia、Vaporwave、Swiss、Y2K；
- **品牌简称**：Apple、Linear、Notion、Stripe；
- **情绪语言**：冷静、危险、温柔、权威、叛逆；
- **材质语言**：玻璃、纸张、金属、胶片、工业塑料；
- **时代与文化**：90 年代杂志、早期互联网、日系街头、博物馆目录；
- **结果语言**：高级、现代、干净、电影感。

“高级、现代、电影感”本身不能直接进入实现，需要继续拆解。

### 2. 候选审美

给出 2–3 个可能方向，并说明它们在当前项目中的差异。不要列出十几个风格让用户猜。

示例：

```text
“cozy retro but not kitsch”可能对应：
A. 温和的 1970s Editorial：纸张色、严谨网格、少量复古摄影；
B. Mid-century Product Modernism：几何形状、清晰功能、明快但克制；
C. Soft Web 2.0 Nostalgia：高光、圆角、轻拟物，更容易滑向可爱和俗套。
推荐 A，因为内容型品牌比产品工具更需要编辑气质，且用户明确排斥 kitsch。
```

只问一个最高价值的消歧问题。

## 三、七维审美画像

对每个候选方向按七个维度研究。不要只给配色和字体。

### 1. Form · 形态

- 几何还是有机；
- 锐利还是柔和；
- 模块化还是连续；
- 规则轮廓还是不规则裁切；
- 控件与内容是否共享形态语言。

### 2. Color · 色彩

- 主氛围来自明度、饱和度还是色温；
- 中性色是否偏暖、偏冷或无色；
- Action 色和 Semantic 色是否独立；
- 色彩是大面积空间还是稀缺强调；
- 深色模式是否属于同一世界。

### 3. Type · 排版

- 字体性格和历史语境；
- 标题、正文、标签、数字的角色；
- 字号比例和断行；
- 对齐、字距、行距和阅读宽度；
- CJK、拉丁、数字和回退字体关系。

### 4. Space · 空间与构图

- 视觉锚点和视线流；
- 对称、非对称或模块化；
- 密疏节奏和留白角色；
- 边缘、出血、裁切和容器宽度；
- 小屏重构方式。

### 5. Material · 材质与深度

- 平面、纸张、玻璃、金属、织物、胶片或数字光；
- 边框、色块、阴影、透明、纹理如何表达层级；
- 哪些材质是文化标记，哪些只是装饰；
- 低性能和 reduced-transparency 如何降级。

### 6. Motion · 动效

- 静态、功能反馈、空间解释、叙事编排或环境运动；
- 时间节奏是否与审美一致；
- 运动是短促、机械、柔和、弹性还是电影式；
- 动画是否具有双向性和退出逻辑；
- reduced motion 是否仍保留概念。

### 7. Cultural Markers · 文化标记与语义

- 哪些视觉信号让该风格被识别；
- 它来自什么年代、亚文化、产业或媒介；
- 在当前受众中可能表达什么身份、阶层、政治或情绪含义；
- 是否存在挪用、刻板印象、错误时代混搭或伦理风险；
- 哪些标记是非谈判项，哪些可以现代化。

## 四、非谈判项与反模式

每个方向必须给出：

### Non-negotiables

至少 2–4 个没有它就不像该方向的信号。例如：

- Risograph：有限色层、套色偏移、纸张颗粒；
- Swiss：严格网格、信息优先、明确类型比例；
- Dark Academia：高密度文字、历史材质、克制而非“棕色滤镜”；
- Y2K：高光塑料、未来乐观主义、早期数字文化，不只是粉色和 Chrome 字体。

### Anti-patterns

说明最容易被 AI 误解的地方：

- 只复制表面颜色；
- 把文化风格变成装饰贴纸；
- 混合多个年代的标记；
- 用通用 Card 和组件骨架承载完全不同的审美；
- 依赖低质量假素材；
- 用风格名为可访问性失败辩护。

## 五、参考三角与六维试吃

不要以一个网站作为完整模板。优先准备 3–5 个参考，并按功能分工：

1. **构图参考**：网格、视线流、Section 节奏；
2. **排版 / 色彩参考**：类型比例、颜色角色、明度关系；
3. **图像 / 材质 / 动效参考**：摄影、纹理、运动和深度；
4. 可选：同类产品参考，用来验证功能和内容；
5. 可选：反参考，用来明确不能滑向什么。

对每个参考按 Form / Color / Type / Space / Material / Motion 六维快速记录：

| 参考 | Form | Color | Type | Space | Material | Motion | 借什么 | 不借什么 |
|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |

最后提炼交集与冲突，而不是平均混合。

## 六、方向胶囊生成

研究完成后生成 2–3 个方向胶囊。它们必须在至少三个维度上显著不同，且至少一个关键差异来自信息结构、交互模型、内容依赖、资产要求或技术复杂度。

### 胶囊模板

```markdown
## Direction A · [名称]

- **视觉命题：**
- **三个气质词 / 反形容词：**
- **主导概念：**
- **主要张力：**
- **信息结构 / 交互模型：**
- **七维摘要：**
- **非谈判项：**
- **适合的内容和资产：**
- **实现复杂度：** 低 / 中 / 高
- **最大收益：**
- **最大风险：**
- **不选择它意味着：**
```

不要把方向 A/B/C 变成同一布局的浅色、深色和紫色版本。明确写出它与其他方向的一个非视觉差异。

## 七、电影 / 导演研究路径

仅在 Persuade 或 Experience 表面，且用户明确希望强叙事、电影感或导演语言时使用。

### 1. 选择研究对象

选择一位导演和一部具体作品，或由用户指定。研究对象是结构灵感，不是视觉复制目标。

### 2. 提取电影语法

研究：

- 镜头距离与构图重心；
- 光线、明暗和色彩分级；
- 场景节奏与停顿；
- 材质、空间和环境；
- 字幕、标题与图形语言；
- 重复意象和转场。

### 3. 转译为网页语法

按顺序输出：

1. **Site-wide grammar**：全站的空间、节奏、类型和色彩规则；
2. **Page scene thesis**：每页像一个什么场景、要产生什么感受；
3. **Signature composition**：一处主导构图；
4. **Shared system**：导航、控件、动效和状态如何保持一致。

不要直接使用电影剧照、角色或可识别版权元素，除非用户拥有权利或只是内部参考。

## 八、品牌系统和知名产品参考

“像 Linear / Stripe / Apple / Notion”通常同时包含多个诉求：

- 信息密度；
- 排版和中性色；
- 组件完成度；
- 动效速度；
- 品牌可信度；
- 技术实现质量。

先询问真正想借的是哪一部分。可以把成熟系统作为 Scaffold，但不得：

- 复制 Logo、命名、专属图形或品牌布局；
- 把知名产品主题当成完整品牌策略；
- 在没有适配内容的情况下复刻其组件；
- 使用“品牌同款”掩盖当前产品没有视觉观点。

## 九、证据与来源

研究结果区分：

- 用户提供的参考；
- 项目现有证据；
- 公开来源；
- 专业推断；
- 暂定假设。

对流派、年代和文化含义不确定时明确说明，不把推测写成历史事实。

## 十、停止条件

当以下条件满足时停止继续找参考：

- 候选方向之间的差异已经清楚；
- 每个方向有非谈判项和风险；
- 用户能依据可观察结果作选择；
- 新增参考不再改变七维画像；
- 当前内容和资产足以支持至少一个方向。

研究不是收藏行为。不能形成实施决策的参考不应继续加载。
