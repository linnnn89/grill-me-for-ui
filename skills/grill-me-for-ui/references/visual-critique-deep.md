# Deep Visual Critique

仅在用户明确要求深度 Critique，或 `visual-critique.md` 的短检查发现 P0/P1 且根因仍不清楚时读取。仍受同一个 Pass 1 → Fix batch → Pass 2 预算约束。

## Contents

1. 印象、缩略与灰度
2. 构图、概念与品牌
3. 排版与视觉系统
4. 动效、平台与真实内容
5. 机械与判断边界

## 1. 五秒印象

看五秒后移开视线：

- 第一眼是什么；
- 这是何种产品、品牌或内容；
- 主要动作或信息是什么；
- 三个气质词是否与 Art Direction Card 一致；
- 能否记住一个明确视觉特征。

若只记住渐变、卡片或动画，却不知道产品是什么，通常是方向或层级问题。

## 2. 缩略与灰度

缩小到文字不可读：

- 仍有清晰锚点和主次；
- 大块明暗关系稳定；
- 密疏节奏有意；
- 首屏不是均匀矩形堆积。

临时移除颜色：

- 层级不依赖颜色；
- 状态有非颜色提示；
- 图片不会压过核心文字；
- 按钮不只靠饱和度获得优先级。

恢复颜色后确认 Atmosphere、Action、Semantic 分工。

## 3. 构图与视线流

- **Anchor**：第一与第二层注意力是否正确；
- **Alignment**：对齐、悬挂、出血和页面边缘是否可解释；
- **Rhythm**：大小、密疏、长短、静动和停顿是否有变化；
- **Tension**：至少一种有意义的对比，一次破格受到系统约束；
- **Flow**：用户是否知道下一步，而非靠滚动猜测结构。

连续重复 Eyebrow + H2 + 说明 + 三张 Card，通常说明结构模板化。

## 4. 概念与品牌指纹

隐藏 Logo、品牌名和明显文案：

- 主导概念贯穿多个区域；
- 支持母题稳定且不竞争；
- 至少三个识别点，其中一个来自构图或系统；
- 替换文案后不能无差别服务任何产品。

“蓝色、圆角、渐变”不足以构成品牌指纹。

## 5. 排版

- 标题、正文、标签、数据和元信息各有稳定角色；
- 断行、孤词、行长、行高和段落宽度有意；
- 小字号与浅色文字不以“精致”为名损害可读性；
- 数字、单位、小数位和表格对齐稳定；
- CJK、拉丁、多语言、长文本和字体回退保持层级。

## 6. 色彩、形状与材质

- 中性色稳定，强调稀缺且有意义；
- 品牌、操作和语义色不混用；
- 形状属于同一家族，Pill 只承担适合的短标签或操作；
- 平面、边框、色块、阴影、透明或纹理有主次；
- Card 与阴影解释真实层级，而不是默认容器。

## 7. 图像、插画、图标与图表

- 素材质量、裁切、镜头、比例和色调支持方向；
- 图片是内容、证据、情绪或叙事，而非随机装饰；
- 插画形成系统，图标使用一个主家族与稳定线宽；
- 图表服务比较、趋势、分布或关系；
- 没有假数据和无法验证的视觉填充。

## 8. 动效

- 动画解释反馈、进出、展开、进度或空间关系；
- 高频操作足够快；
- 进入和退出成对，能够打断；
- 无持续循环运动无理由争夺注意力；
- reduced motion 保留信息；
- 技术复杂度与收益相称。

## 9. 响应式与平台

- 移动端重新决定第一屏、导航和主要动作；
- 表格、图表、画布和全幅影像有明确策略；
- Hover 转换为触控逻辑；
- 平台原生导航、手势、反馈和安全区合理；
- 无横向溢出、遮挡或不可达操作。

## 10. 真实与极端内容

至少测试：

- 最长标题、多语言与 200% 放大；
- 空数据、部分数据和极大数值；
- 慢网络、资源失败和低质量图片；
- 错误、权限、禁用与恢复呈现；
- 长列表、表格和滚动。

理想状态不能掩盖真实内容下的崩溃。

## 11. 机械与判断边界

机械检查适合对比度、Label、alt、Focus、溢出、点击目标、资源、语义结构、reduced motion 和性能。

专业判断用于 Art Direction、锚点、构图、节奏、品牌指纹、参考转译与动效因果。自动规则不能替代审美，Critique 也不能把机械错误包装成偏好。

完成定位后返回 `visual-critique.md` 形成唯一 Fix batch，不在本文件开启新一轮。
